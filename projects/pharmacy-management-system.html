Pharmacy Management System

A Windows Forms application for pharmacy inventory, sales, billing and prescription tracking, backed by SQL Server.

Type
Desktop software
Stack
C#, .NET Framework, SQL Server, Windows Forms
Year
2025

Overview

A desktop application that a pharmacy can use to keep track of its medicine stock, record sales and print bills, and keep prescription records in one place.

What it does

  • Inventory tracking for medicines, with stock levels kept in SQL Server.
  • Sales and billing workflows for staff and customers.
  • Prescription tracking and sales reporting.
  • Windows Forms interface designed around what pharmacy staff do every day.
  • Object-oriented structure so new features can be added without rewriting existing code.
